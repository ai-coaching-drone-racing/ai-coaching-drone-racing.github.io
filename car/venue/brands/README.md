# Venue Brand Graphics

The wall strips and small flags use the original supplied images, fitted
without stretching or recoloring. PNG source files are preserved verbatim.
Runtime canvas layout combines the images into small print textures rather
than uploading the large original files as GPU textures.

Logos retain their respective owners' rights. They are shown as requested
project branding in a competition-style layout, not as a claim of official
sponsorship or institutional endorsement. No new license is granted.

All boards, fixings, flags and pennants are renderer-only. They do not modify
the warehouse, gate geometry, collision model, simulation or controllers.
Original warehouse mode hides the added branding with other venue styling.
